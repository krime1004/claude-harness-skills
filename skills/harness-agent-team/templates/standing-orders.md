# 상시 지시

모든 팀 역할이 매 실행 시작 때 읽는 지시다. 한 줄에 제약 하나만 적고 번호를 붙인다.

- 사용자가 같은 지시를 두 번째로 하면, 메인 세션이 따르기 전에 여기에 한 줄 추가하고 이 파일만 커밋한다.
- 기계적 검사로 강제할 수 있게 된 지시는 검사로 옮기고 여기서 지운다(harness-engineering `references/rule-enforcement.md`).
- 팀 전체를 멈춰야 하면 맨 위에 `0. 정지: <이유>`를 적는다. 진행 중인 실행이 끝나면 원인을 고치고 지운다.

1. (예) push, 배포, 서명은 하지 않는다.
