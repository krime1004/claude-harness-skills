# 팀 실행 기록

에이전트 팀 실행마다 회고 단계가 한 줄씩 추가한다. 모델 자동 조정의 근거다. 규칙은 `harness-agent-team` 스킬의 `references/workflow-orchestration.md` "모델 배정과 자동 조정".

- 모델: 실행에 쓴 단계별 모델
- 조각: 조각마다 설계·검증 라운드, 반려 주체, "QA 통과·레드팀 반려" 횟수, 보류
- 센 실행: 설계가 있었거나 조각 2개 이상이면 "예"(이 실행만 내리기 횟수에 센다)
- 토큰·시간: 메인 세션이 Workflow 완료 알림 값으로 채운다
